# 智能人力资源管理系统 - 职位与简历管理功能矩阵

## 核心概念

本系统的职位管理与简历库管理模块是招聘流程的两大核心组件：
- **职位管理**：用于创建、发布和管理招聘需求，是招聘流程的起点
- **简历库管理**：用于收集、存储和处理应聘者简历，是招聘决策的数据基础

# 智能人力资源管理系统 - 招聘流程功能矩阵

## 招聘流程功能对比

本文档按照完整招聘流程的顺序，展示不同订阅计划在各环节的具体功能差异，帮助您更好地理解各订阅计划的价值。

> **特别说明**: 本系统中有两个核心资源库概念：
> 1. **简历库**：招聘过程中直接交互的资源池，包含待处理的应聘者简历，是招聘流程各环节的实时工作对象。
> 2. **人才库**：独立于招聘流程的长期人才储备资源池，储存已筛选、评估过的优质人才信息，可在任何招聘环节将符合条件的人才添加至该库中，便于长期人才储备和管理。

## 总结

本系统设计明确区分了两个核心资源池：**简历库**和**人才库**。

- **简历库**是招聘流程中的工作对象，管理当前招聘活动中的应聘者简历，用于日常筛选、面试和评估过程中的实时交互。

- **人才库**则是超越单次招聘流程的长期人才储备池，用于储存和管理那些经过筛选评估的高价值人才，可以在未来的招聘需求中快速匹配。

在招聘的各个环节中，系统支持将符合条件的简历或候选人从简历库转入人才库，实现从招聘活动到长期人才储备的价值转化。不同订阅计划在简历库、人才库管理和招聘流程各环节提供了差异化的功能，以满足不同规模企业的需求。

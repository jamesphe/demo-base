# 智能人力资源管理系统 - 招聘流程功能矩阵（简化版）

## 核心概念

本系统包含两个关键资源池：
- **简历库**：招聘过程中直接交互的工作对象，存储当前招聘活动的应聘者简历
- **人才库**：长期人才储备资源池，保存已筛选评估过的优质人才信息

系统支持在各招聘环节将优质简历/候选人从简历库转入人才库，实现从招聘活动到战略人才资源的价值转化。

# 智能人力资源管理系统 - 面试流程与菜单设计文档

## 一、系统菜单架构

### 1. 顶级菜单结构
```
├── 控制台                   // 系统概览与快捷入口
├── 职位管理                 // 职位相关功能
├── 简历管理                 // 简历相关功能
├── 面试管理                 // 面试相关功能
├── 候选人管理               // 候选人跟踪与人才库
├── 招聘分析                 // 数据分析功能
└── 系统设置                 // 系统配置功能
```

### 2. 面试管理子菜单
```
├── 面试管理
│   ├── 面试安排             // 安排新面试与时间管理
│   ├── 面试记录             // 所有面试记录列表
│   ├── 面试评估             // 评估结果与决策支持
│   └── 面试统计             // 面试结果与转化率统计
```

### 3. 隐藏菜单页面（功能页面）
```
├── 面试管理（隐藏页面）
│   ├── 面试准备/:id         // 面试前准备与材料
│   ├── 面试实时记录/:id     // 面试过程记录界面
│   ├── 面试反馈/:id         // 面试反馈与评价汇总
│   └── 面试决策/:id         // 最终招聘决策页面
```

## 二、详细面试流程与对应页面

### 1. 面试安排阶段

**菜单项**: 面试管理 > 面试安排
**页面路径**: `/interview/schedule`
**组件名**: InterviewSchedule
**显示状态**: 主菜单可见项
**访问角色**: tenant_admin, tenant_hr, interviewer

**核心功能**:
- 创建新面试，选择面试类型（初试/复试/终试）
- 设置面试时间、地点、时长
- 选择面试官和候选人
- 检测时间冲突并提供建议
- 发送面试邀请通知
- 查看已安排面试列表并支持筛选

**操作流程**:
1. 从职位申请或简历搜索中选择候选人
2. 在面试安排界面设置面试信息
3. 选择面试官并检查时间冲突
4. 创建面试并发送通知

### 2. 面试准备阶段

**菜单项**: (隐藏，通过面试安排或面试记录页面进入)
**页面路径**: `/interview/preparation/:id`
**组件名**: InterviewPreparation
**显示状态**: 隐藏菜单项
**访问角色**: tenant_admin, tenant_hr, interviewer

**核心功能**:
- 查看候选人简历的详细信息
- 查看职位描述和要求
- AI生成面试问题和关注点
- 自定义面试关注点和话题
- 上传或生成面试指南文档
- 查看候选人历史面试记录（如有）

**访问方式**:
1. 面试安排页面的"准备面试"按钮
2. 面试记录列表中的"面试准备"操作
3. 面试通知邮件中的准备链接

### 3. 面试进行阶段

**菜单项**: (隐藏，通过面试记录页面进入)
**页面路径**: `/interview/process-record/:id`
**组件名**: InterviewProcessRecord
**显示状态**: 隐藏菜单项
**访问角色**: tenant_admin, tenant_hr, interviewer

**核心功能**:
- 面试计时器工具
- 实时记录问答内容的编辑区
- 快速添加时间戳标记
- 一键标记关键优势/不足/疑问
- 技术能力、沟通能力等各维度评分
- 提供面试记录模板和快捷短语
- 查看面试准备材料参考
- 草稿自动保存功能

**访问方式**:
1. 面试记录列表中的"开始记录"按钮
2. 面试详情页中的"实时记录"入口
3. 面试通知中的直接链接

### 4. 面试反馈汇总阶段

**菜单项**: (隐藏，多种方式访问)
**页面路径**: `/interview/feedback/:id`
**组件名**: InterviewFeedback
**显示状态**: 隐藏菜单项
**访问角色**: tenant_admin, tenant_hr, interviewer

**核心功能**:
- 显示本人提交的面试反馈详情
- 查看其他面试官的反馈汇总（权限控制）
- 统计候选人评价的关键优势和不足
- 展示各维度评分的平均值和分布
- 显示招聘建议的统计结果
- 提供反馈修改和补充功能
- 支持反馈详情导出

**访问方式**:
1. 面试记录提交后自动跳转
2. 面试记录列表中的"查看反馈"按钮
3. 面试详情对话框中的反馈标签页
4. 候选人详情页面的面试反馈部分
5. 收到的反馈填写提醒通知
6. URL直接访问（需权限验证）

### 5. 面试评估阶段

**菜单项**: 面试管理 > 面试评估
**页面路径**: `/interview/evaluation/:id`
**组件名**: InterviewEvaluation
**显示状态**: 主菜单可见项(访问具体评估为隐藏路由)
**访问角色**: tenant_admin, tenant_hr

**核心功能**:
- 综合多位面试官的反馈进行最终评估
- 结构化评估表单（技术能力、沟通能力等）
- 录用决策支持（通过/不通过/待定）
- 设置后续流程建议（复试/终试/发offer）
- 添加HR评语和建议
- 更新面试状态
- 发送评估结果通知

**访问方式**:
1. 面试管理菜单直接进入评估列表
2. 面试记录列表中的"评估"按钮
3. 面试反馈页面的"评估"入口
4. 候选人详情页的评估入口

### 6. 面试记录管理

**菜单项**: 面试管理 > 面试记录
**页面路径**: `/interview/record`
**组件名**: InterviewRecord
**显示状态**: 主菜单可见项
**访问角色**: tenant_admin, tenant_hr, interviewer

**核心功能**:
- 所有面试记录的列表查看
- 多条件筛选（状态、时间、面试官等）
- 面试详情查看
- 面试状态追踪和更新
- 面试报告导出
- 相关操作入口（准备、记录、反馈、评估）
- 后续面试安排（针对复试/终试）

**特殊功能**:
- 面试录音/视频关联（如有）
- 面试评价对比分析
- 面试过程记录的完整性检查

## 三、多轮面试流程设计

### 1. 初试 (first)
- **目标**: 基础筛选，确认候选人基本能力与岗位匹配度
- **参与角色**: 技术面试官/业务部门
- **关注点**: 基础技能验证、经验真实性、沟通能力初步评估
- **决策**: 通过/不通过/待定

### 2. 复试 (second)
- **目标**: 深入评估候选人专业能力和潜力
- **参与角色**: 资深面试官/部门主管
- **关注点**: 专业深度、解决问题能力、团队协作能力
- **决策**: 通过/不通过/加试

### 3. 终试 (final)
- **目标**: 全面评估，确认文化匹配度和职业发展规划
- **参与角色**: 部门负责人/高管
- **关注点**: 价值观匹配、领导力潜质、长期发展规划
- **决策**: 通过(发offer)/不通过

## 四、角色权限与访问控制

### 1. 系统角色定义

| 角色 | 描述 | 面试流程权限 |
|------|------|------------|
| admin | 系统管理员 | 全部权限（一般不参与具体业务） |
| tenant_admin | 租户管理员 | 所有面试流程的管理权限，可查看所有面试记录和统计 |
| tenant_hr | HR专员 | 安排面试、查看所有面试记录、进行最终评估 |
| interviewer | 面试官 | 参与面试、记录面试过程、提交面试反馈 |
| tenant_viewer | 观察者 | 只读权限，可查看面试记录但不能操作 |

### 2. 页面访问权限矩阵

| 页面/功能 | admin | tenant_admin | tenant_hr | interviewer | tenant_viewer |
|----------|-------|--------------|-----------|-------------|---------------|
| 面试安排 | ✅ | ✅ | ✅ | ⚠️(仅参与) | ❌ |
| 面试记录 | ✅ | ✅ | ✅ | ⚠️(仅参与) | ✅(只读) |
| 面试准备 | ✅ | ✅ | ✅ | ✅ | ❌ |
| 实时记录 | ✅ | ✅ | ✅ | ✅ | ❌ |
| 面试反馈 | ✅ | ✅ | ✅ | ⚠️(仅参与) | ❌ |
| 面试评估 | ✅ | ✅ | ✅ | ❌ | ❌ |
| 面试统计 | ✅ | ✅ | ✅ | ❌ | ✅(只读) |

注: ⚠️表示有限权限，例如面试官只能查看自己参与的面试记录

## 五、面试数据流转与状态管理

### 1. 面试状态流转

```
预约(scheduled) → 进行中(in_progress) → 已完成(completed) → 已评估(evaluated)
                 ↘                                       ↗  
                   → 已取消(cancelled) →
```

### 2. 面试信息流转
1. 职位申请 → 简历筛选 → 安排面试
2. 面试准备 → 面试记录 → 面试反馈 → 面试评估
3. 初试 → 复试 → 终试 → Offer/拒绝

### 3. 关键数据存储项
- 面试基本信息(时间、地点、类型等)
- 面试官记录内容(process_record)
- 各维度评分(technical_evaluation, comprehensive_evaluation)
- 总体评价(summary, evaluation_score)
- 招聘建议(hiring_recommendation)
- 最终决策(result, comments)

## 六、实现技术与注意事项

1. **响应式设计**：确保在不同设备上都能高效使用
2. **实时保存**：面试记录过程采用自动保存机制
3. **权限隔离**：严格控制不同角色对面试数据的访问权限
4. **数据安全**：敏感候选人信息加密存储，访问日志记录
5. **高效导航**：虽有隐藏页面，但确保操作流程中的自然跳转
6. **离线支持**：面试记录支持离线模式，连接恢复后自动同步

## 七、界面设计建议

### 面试安排界面
- 日历视图与列表视图切换
- 拖拽操作支持快速调整面试时间
- 冲突检测与可视化提示
- 批量操作支持（群面场景）

### 面试记录界面
- 分栏布局，左侧记录区，右侧参考资料
- 记录工具栏，支持快捷操作
- 自动保存指示器
- 模板快速插入功能

### 面试反馈界面
- 评分卡片式布局
- 可视化评分统计（雷达图、柱状图）
- 关键字标签云展示优势/不足
- 分享与导出功能

### 面试评估界面
- 决策辅助展示板
- 候选人全面评价汇总视图
- 同岗位候选人对比功能
- 评估流程状态指示

通过这种详细的菜单设计和面试流程规划，系统能够支持企业从初试到终试的完整面试过程，确保招聘流程的规范化、数据化和高效化。

# **AI智能招聘管理系统报价单**



## **概述**



本报价单针对企业招聘流程智能化、自动化的需求，提供了覆盖职位发布、简历管理、面试组织与数据分析全链条的一体化解决方案。系统基于模块化设计，支持灵活选配，结合AI智能技术大幅提升招聘效率与质量。同时，系统支持本地化部署买断和订阅两种模式，便于企业根据自身实际情况灵活选择，所有部署均需客户自备部署环境。报价单详细列出了各功能模块、单项价格及技术服务内容，便于客户根据需求进行定制配置与预算规划。

## 部署环境

### 服务器配置要求

| 服务器类型 | 建议配置 | 说明 |
|------------|----------|------|
| 应用服务器 | CPU: 8核+<br>内存: 32GB+<br>存储: 300GB+ SSD<br>网络: 千兆网卡 | 运行Docker容器，包括：<br>- 后端服务<br>- Celery任务队列<br>- Redis缓存<br>- Nginx前端服务<br>建议使用SSD存储以提高性能 |
| 数据库服务器 | CPU: 8核+<br>内存: 32GB+<br>存储: 1TB+ SSD<br>网络: 千兆网卡 | 独立运行PostgreSQL数据库<br>建议使用SSD存储以提高数据库性能<br>建议配置RAID 10以提高数据安全性 |
| 备份服务器 | CPU: 4核+<br>内存: 16GB+<br>存储: 1TB+<br>网络: 千兆网卡 | 用于数据备份和容灾 |

### 软件环境要求

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| 操作系统 | Linux (CentOS 7+/Ubuntu 20.04+) | 推荐使用主流 Linux 发行版 |
| Docker | 20.10.0+ | 容器运行环境 |
| Docker Compose | 3.8+ | 容器编排工具 |
| PostgreSQL | 14+ | 数据库服务 |
| Redis | 7+ | 缓存和消息队列服务 |
| Nginx | 1.18+ | Web服务器和反向代理 |

### 大语言模型服务要求

| 服务类型 | 配置要求 | 说明 |

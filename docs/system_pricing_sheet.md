## 客户自备硬件环境要求

**注意：以下设备需由客户自行准备，不包含在本报价中**

### 标准版推荐配置
- 应用服务器：2核8G，100GB存储
- 数据库服务器：可与应用服务器共用
- 数据库：MySQL 5.7+
- 操作系统：CentOS 7/8，Windows Server 2016+
- 网络：内网部署或VPN访问

### 高级版推荐配置
- 应用服务器：4核16G，200GB存储
- 数据库服务器：4核16G，300GB存储
- 数据库：MySQL 5.7+或Oracle 11g+
- 操作系统：CentOS 7/8，Windows Server 2016+
- 网络：内网部署，可配置外网访问

### 企业版推荐配置
- 应用服务器集群：2-4台，每台8核32G，200GB存储
- 数据库服务器：8核32G，500GB+ SSD存储
- 负载均衡设备：1-2台
- 数据库：MySQL集群或Oracle 12c+
- 操作系统：CentOS 7/8，RHEL 7/8
- 网络：企业级网络架构，支持内外网隔离访问

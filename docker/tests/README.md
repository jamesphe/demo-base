# 性能测试脚本使用说明

此目录包含用于性能测试的 k6 脚本。测试主要针对活动系统的关键 API，特别是出现 500 错误的接口。

## 测试内容

当前测试脚本包括以下测试场景：

1. 健康检查接口测试
2. 用户登录接口测试
3. 获取活动详情接口测试
4. 获取活动奖品列表接口测试（服务器端返回 500 错误的接口）

## 运行测试

### 使用 Docker Compose 运行测试

在服务器上，进入 docker 目录后执行：

```bash
docker-compose -f docker-compose.test.yml up --build
```

### 测试参数调整

您可以在 `docker-compose.test.yml` 中调整以下性能测试参数：

- `K6_VUS`：并发虚拟用户数
- `K6_DURATION`：测试持续时间
- `K6_BACKEND_URL`：后端 API 的基础 URL

### 分析测试结果

测试完成后，k6 将提供详细的性能指标报告，包括：

- 响应时间分布（最小、最大、平均、中位数、p95、p99）
- 每秒请求数
- 各 API 的请求成功率和错误率
- 错误详情

您可以重点关注：

1. 获取活动奖品列表接口的错误率和错误类型
2. 在高并发下，系统的响应时间变化
3. 系统资源（CPU、内存、网络）利用率

## 问题排查

如果发现 `api/activities/{id}/prizes` 接口返回 500 错误，请检查：

1. 数据库连接是否正常
2. 相关活动 ID 是否存在
3. 奖品表数据是否完整
4. 应用日志中的详细错误信息
5. 数据库查询是否优化
